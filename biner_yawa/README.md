# Hotel Paradise Website

A responsive hotel website built with PHP and Bootstrap.

## Pages

- **Homepage (index.php)**: Welcome page with hero section and feature cards
- **Login (login.php)**: User login form
- **Sign Up (signup.php)**: User registration form with validation
- **About (about.php)**: Information about the hotel
- **Contact (contact.php)**: Contact form and location map

## Features

- Responsive design using Bootstrap 5
- Consistent navigation and footer across all pages
- Form validation on sign up page
- Google Maps integration on contact page
- Placeholder images (replace with actual hotel images)

## Setup

1. Place the files in your web server's document root (e.g., htdocs for XAMPP)
2. Ensure PHP is enabled on your server
3. Access the site via your browser (e.g., http://localhost/index.php)

## Technologies Used

- PHP
- Bootstrap 5
- HTML5
- CSS3
